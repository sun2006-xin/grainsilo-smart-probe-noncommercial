# 电脑端运行与数据说明

## 普通用户运行

1. 下载 releases/GrainSilo-Desktop-Windows-x64.zip。
2. 在 Windows x64 上解压整个文件夹。
3. 双击 粮仓集成监控中心.exe，等待控制窗口显示“中心站运行中”，浏览器会自动打开本机监控页。
4. 保持控制窗口运行。点“退出并停止中心站”会停止服务，并提示 S3 暂时不能上传。

这是便携版而非安装程序；不要求管理员权限，不会自动修改防火墙，也没有自动桌面快捷方式。不要只复制 EXE 文件。

ZIP 根目录和 `SOURCE-CODE/` 中均附有与该电脑中心站相对应的 GrainSilo 软件 `LICENSE`；源码目录还包含 Python 源码、网页资源、构建脚本、构建依赖和相关第三方许可证。软件非商业许可不覆盖 S3/C3 固件所依赖的 AutoLink 私有库，详见许可原文。

## 网络与端口

- 默认 TCP 8000；如果已有程序占用，应用会报错而不会关闭旧服务。
- 为接入 S3，需要由电脑管理员创建只允许可信局域网设备访问该 EXE 的防火墙规则。规则按实际 IP/地址规划配置，发布文档不得硬编码本机 IP。
- 中心站当前无用户登录认证。只在可信私有网络中测试；不要对公网开放 8000，也不要配置路由器端口转发。
- S3 主动连接电脑中心站，需在 S3 配置页填写电脑在家庭/实验网络中的 IPv4 地址。无需让 PC 端扫描探杆。

**设备网页安全提醒：** S3 调试模式还会在 TCP 80 提供未加密且无登录认证的设备网页。若未配置家庭 Wi-Fi 或连接失败，S3 会启动无密码的 `GrainSilo-XXXX` 配网热点。连接热点或同一局域网的用户可以读取状态，并更改 Wi-Fi/中心站地址、告警阈值、采样周期和运行模式，也能重启或触发上报。此功能仅供可信个人/实验网络；不要在设备网页提交需要保密的 Wi-Fi 密码，不要把设备端口暴露到公网。此固件安全边界尚未完成加固或现场安全验证。

## 本地持久化

冻结版用户数据保存在 %LOCALAPPDATA%\GrainSilo\station.db，启动日志保存在同目录下的 logs。程序包不包含项目开发库、论文实验记录、设备 UID 或用户网络配置。升级/重新解压便携文件不应覆盖该目录；用户仍应自行定期备份数据库。

## 外部天气与位置服务

- 浏览器定位需要用户授权，只填入候选坐标；必须确认后才能保存到当前仓库。
- 中心站不集成服务端 IP 地址定位 API。浏览器当前位置需要用户授权，具体定位提供方及网络行为取决于浏览器/操作系统；城市检索使用 Open-Meteo 地名服务，手动坐标可不经过地名检索。
- 城市检索/天气预报/历史天气会向天气服务发送所选仓库的经纬度与请求时间范围。若不愿向外部服务提供坐标，可不使用天气功能并手动配置/留空位置。
- 逐小时天气是网格模型数据，不是粮仓现场气象站实测。天气辅助模型只有在历史逐小时配对覆盖充分并通过时间留出验证时才应给出预测。

## 预测、告警与安全边界

- 空气相对湿度（%RH）不是粮食含水率。
- 电脑端的“历史不足/预测不可用”是有效的数据质量状态，不应被改成看似确定的数值。
- 探杆单点只代表传感器附近空气；不能直接推断整仓温湿度。
- 采样周期或阈值只有在固件收到配置并回执后才算实际生效；中心站数据库中保存“目标配置”不等于设备确认。
- 当前版本未认证、未签名、未经工业现场安全或精度认证。应先在低风险实验环境验证，不能作为唯一粮食安全或通风控制依据。
