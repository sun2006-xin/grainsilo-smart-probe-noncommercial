# Windows 便携包对应源码

ZIP 内的 SOURCE-CODE/ 目录包含与“粮仓集成监控中心.exe”对应的电脑端应用源码、网页资源、构建脚本、构建依赖说明和相关许可证。可在 Windows PowerShell 与 Python 3.11 环境中运行仓库工具目录下的 build_station_user.ps1 重新构建；脚本会创建隔离构建环境并下载固定版本的 PyInstaller 依赖。

该源码包不包含 S3/C3 固件。固件依赖目前未公开的 AutoLink 协议库，因此需要项目所有者另行授权提供的依赖和适配，不能仅凭此源码包独立构建。
