## 天气与地名服务

- 天气、逐小时预报和历史天气：Open-Meteo。天气数据采用 CC BY 4.0 并要求署名；免费 API 的使用范围受 Open-Meteo 条款约束。
- 地名检索：Open-Meteo Geocoding 使用 GeoNames 数据，页面提供 GeoNames 来源署名。
- 位置：应用不集成服务端 IP 定位 API。浏览器定位需由用户授权；也可用城市检索或手工坐标。用户确认后才将坐标保存到相应仓库。
- 天气请求会包含用户选择的仓库坐标和请求时间范围。网格天气是外部模型数据，不是仓内或当地现场气象站实测。

具体服务条款和署名方式可能更新，用户使用前应查看服务方当前说明。相关服务和数据边界见资源来源与外部服务说明。
