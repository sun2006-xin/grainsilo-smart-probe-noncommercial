## 运行时外部服务

电脑端的本地采集、SQLite 历史库和主要网页不依赖云账号。天气和地名搜索使用 Open-Meteo 服务；城市地名数据署名 GeoNames。天气请求发送所选仓库坐标和时间范围。浏览器定位由用户显式授权，具体定位提供方与网络行为由浏览器/操作系统决定；用户也可搜索城市或手动输入坐标。不使用天气功能时可以不配置位置。

天气网格数据不是仓房实测天气。服务条款、额度和端点可能变化，使用前请查看 Open-Meteo 与 GeoNames 当前说明。
