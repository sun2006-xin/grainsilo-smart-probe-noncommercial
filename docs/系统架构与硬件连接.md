## 当前原型结构

当前实物范围：一根探杆、三个 ESP32-C3 测量节点和一个 ESP32-S3 主机。每个节点的 ESP32-C3、MAX3485 RS-485 收发器与 SHT31 温湿度传感器集成在一块小型电路板上。节点安装在长而光滑的探杆结构内；通信地址不代表节点在探杆上的物理高度。

## 供电与四芯总线

- 两芯供电输入先到 S3 主机侧。
- 从 S3 侧引出四芯主干：RS-485 A、RS-485 B、VCC、GND。
- 三个节点分别从四芯主干分支，并联到总线上：A 接 A，B 接 B，VCC/GND 接对应供电线。
- 四芯主干不包含 I²C、UART TX/RX 或方向控制信号。

概念连接如下：

    两芯供电输入 VCC/GND
              │
              ▼
    S3 主机侧：ESP32-S3 + 本地 MAX3485
              │
              └── 四芯主干：A / B / VCC / GND ──┬── 节点 1 分支
                                                  ├── 节点 2 分支
                                                  └── 节点 3 分支

## 节点与主机本地连接

每个节点内部：

- ESP32-C3 通过本地 I²C 连接该节点的 SHT31；
- ESP32-C3 通过本地 UART 和方向控制连接该节点的 MAX3485；
- MAX3485 的 A/B 接入四芯主干。

S3 主机内部：

- ESP32-S3 通过本地 UART 和方向控制连接主机侧 MAX3485；
- MAX3485 的 A/B 接入四芯主干；
- OLED 使用主机侧本地 I²C 连接；
- S3 通过 Wi-Fi 向同一可信局域网中的 Windows 本地中心站主动上报数据。

## 固件 GPIO 映射

以下编号来自本仓库中的 GrainSilo 固件配置。实际板卡可能有变体；连接前仍需核对真实开发板、MAX3485 小板丝印和固件版本。

| 控制板 | 功能 | GPIO |
|---|---|---:|
| ESP32-C3 节点 | UART TX → MAX3485 DI | 6 |
| ESP32-C3 节点 | UART RX ← MAX3485 RO | 7 |
| ESP32-C3 节点 | RS-485 方向控制 | 10 |
| ESP32-C3 节点 | SHT31 SDA / SCL | 4 / 5 |
| ESP32-S3 主机 | UART TX → MAX3485 DI | 17 |
| ESP32-S3 主机 | UART RX ← MAX3485 RO | 16 |
| ESP32-S3 主机 | RS-485 方向控制 | 4 |
| ESP32-S3 主机 | OLED SDA / SCL | 8 / 9 |
| ESP32-S3 主机 | 电池分压采样 ADC | 5（经分压电路） |

MAX3485 的发送/接收方向控制和 /RE 接法须以实际模块电路为准。不要仅凭 EN、RE 或 DE 丝印推断引脚已在模块内部连接。

## 供电和布线注意事项

四芯主干中的 VCC/GND 是系统供电支路。供电电压、S3 侧供电来源和稳压能力、三节点峰值电流、线缆长度及压降必须按实际硬件核验；本图不指定未经验证的电压或电流能力。点亮不等于通过长期供电测试。

RS-485 A 接 A、B 接 B，并保持系统共地。线长、波特率、支线长度、终端电阻和偏置应作为现场布线的独立验证项；短跳线测试不代表大型粮仓布线验收。

## 节点地址与物理位置

AutoLink 通信地址用于通信识别，不能用来推断探杆上部、中部或下部。每根探杆都需要单独记录测点的物理坐标或深度并现场校准，校准后才能在界面中绑定位置标签。

## 电脑端和网络

S3 是主动上报方，向同一局域网中的电脑中心站发送数据；电脑端不扫描或主动寻找探杆。默认中心站 TCP 8000；S3 设备网页为未加密 HTTP，且无登录认证。当前只面向可信个人/实验网络，不要把设备页或中心站端口映射到公网。
